# Арома Дом

Меняйло Никита, РПО1. Вариант 6. Единый проект по модулям 1–4.

Приложение для учёта материалов производства декоративных свечей.
C#, WPF, .NET Framework 4.8, Microsoft SQL Server.
Python используется только для генерации SQL из Excel в модуле 1.

## Возможности

- Модуль 1: база AromaDom_V6, таблицы, связи и импорт исходных Excel-файлов.
- Модуль 2: карточки материалов и сумма расхода материала по рецептурам.
- Модуль 3: добавление и редактирование материалов, проверка ввода, обновление списка.
- Модуль 4: продукция по выбранному материалу и расчёт количества изделий с учётом потерь.

Это одна итоговая версия приложения: отдельные старые программы запускать не нужно.

## Запуск

1. Если базы AromaDom_V6 ещё нет, выполните `Database/AromaDom.sql` в SSMS.
   Если база уже создана в модуле 1, SQL повторно запускать не нужно.
2. В `Ready/AromaDomWpf_Module4.exe.config` проверьте `Data Source`.
   По умолчанию используется `.\SQLEXPRESS` и проверка подлинности Windows.
3. Запустите `Ready/AromaDomWpf_Module4.exe`.

EXE и его файл `.config` должны находиться рядом. Требуются Windows,
.NET Framework 4.8 и доступ к SQL Server. Python для запуска приложения не нужен.

Нажатие на карточку открывает редактирование. «Добавить» создаёт материал.
«Продукция» показывает товары, в которых используется выбранный материал.
«Расчёт» открывает калькулятор. «Назад» закрывает дополнительную форму без сохранения.

## Расчёт продукции

`ProductionCalculator.CalculateProducts(productTypeId, materialTypeId,
rawQuantity, parameter1, parameter2)` получает коэффициент и процент потерь из БД.

Расход на изделие = параметр 1 × параметр 2 × коэффициент типа продукции.
Доступное сырьё = количество сырья × (1 − процент потерь / 100).
Результат — целая часть отношения доступного сырья к расходу на изделие.
Неверные параметры и отсутствующие типы возвращают −1. Ноль сырья даёт 0.
Ошибки соединения с БД показываются отдельно.

Пример: сырьё 100, параметры 2 и 3, коэффициент 2, потери 10% — 7 изделий.
В исходных данных loss_percent = 0.12 означает 0,12%, а не 12%.

## Повторная генерация SQL

В папке Database выполните:

```text
python -m pip install -r requirements.txt
python generate_sql.py
```

Генератор создаёт AromaDom.sql из файлов data. Сам он не подключается к серверу.
В базе: 10 типов материалов, 6 типов продукции, 18 материалов,
14 товаров и 73 записи рецептур.

## Проверки и ограничения

Обе версии WPF собраны без ошибок и предупреждений. Проверены числовой ввод,
округление, граничные значения расчёта и отображение четырёх форм.
Полный цикл записи в действующую базу пользователя из среды сборки не проверялся.

В ресурсах задания нет отдельного логотипа и иконки. Использованы шрифт Georgia
и цвета из руководства по стилю.
`Database/ER_diagram.pdf` подготовлена по SQL; это не экспорт из SSMS.
Для строгого выполнения модуля 1 замените её диаграммой из своей СУБД.
